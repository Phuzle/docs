---
title: Limits
description: Free tier limits and how they behave.
---

| Limit | Free tier |
|---|---|
| Members per org | 1 |
| Topics | 10 |
| Devices per topic | 5 |
| API keys | 10 |
| Triggers per day (per org) | 1,000 |
| Plaintext size | 2 KiB |
| Actions per message | 3 |
| Delivery-log retention | 30 days |
| Live pairing links | 20 |

Going over the daily cap returns `429 quota_exceeded` with a `Retry-After` header. Limits are
configuration, so they may change.

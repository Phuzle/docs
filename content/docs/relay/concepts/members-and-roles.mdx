A Relay account can belong to **several organizations**; the switcher in the sidebar picks the one you are working in. Each organization has its own plan, topics, devices and keys.

## Roles

| | Member | Admin | Owner |
|---|---|---|---|
| See topics, devices, activity, members | ✓ | ✓ | ✓ |
| Send a test notification | ✓ | ✓ | ✓ |
| Create topics, pair devices, manage integrations | | ✓ | ✓ |
| API keys | | ✓ | ✓ |
| Invite and remove members, rename the org | | ✓ | ✓ |
| View billing | | ✓ | ✓ |
| Make or remove admins, request a plan change | | | ✓ |
| Transfer ownership, delete the organization | | | ✓ |

The owner can't be removed or leave without transferring ownership first.

## Inviting people

Admins create a **single-use invite link** (valid for 1, 3 or 7 days). You can limit it to one Google account. The person opens the link, signs in with Google and joins with the role you picked. Revoke a pending link any time.

<Callout type="info" title="Seats depend on the plan">
	Free and Pro organizations have one seat, so only **Team** organizations can have members. Pending invites count towards the seat limit.
</Callout>

## Your free organization limit

You can own up to **5 free organizations**. Upgrading one to a paid plan frees a slot. Joining someone else's organization never counts towards the limit.

## Leaving and deleting

Members can leave an organization from the Members page. Deleting an organization (owner only) archives its topics and revokes its API keys; its URL name stays reserved. Deleting your account removes organizations only you belong to; if you own one with other members, transfer it first.

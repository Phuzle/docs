---
title: Pairing links
description: How QR codes and links add a phone to a topic.
---

A pairing link looks like `https://relay.phuzle.com/p#<token>`. With the Relay app installed it opens
the app directly (Android App Links); otherwise the page explains how to install it. The app also
accepts `relay://pair?t=<token>`.

- The token is in the URL **fragment**, so it is never sent to a web server or logged by one.
- It is **single-use** and expires after 15 minutes, 1 hour, or 24 hours.
- The app first *previews* the topic and org without using the token, then you confirm.
- Revoke any live link from the topic's Devices tab.
- Whoever confirms first gets the device paired; treat a link like a password until it is used.

```bash
npm i @phuzle/relay      # or: bun add @phuzle/relay · pnpm add @phuzle/relay
```

Node 20+ or Bun. The package ships ESM and CommonJS builds with TypeScript types, and the encryption runs on your machine.

```ts
import { Relay, RelayError } from "@phuzle/relay";

const relay = new Relay({ apiKey: process.env.RELAY_API_KEY! });

try {
  const r = await relay.send({
    topic: "acme-alerts",
    title: "api-3 is unhealthy",
    body: "3 failed health checks in a row",
    priority: "urgent",
    tags: ["prod"],
    idempotencyKey: "healthcheck-api-3-2026-10-05T10",
  });
  console.log(r.accepted, r.rejected, r.missing);
} catch (e) {
  if (e instanceof RelayError) console.error(e.status, e.message);
}
```

## Behaviour

- Encrypts locally, one envelope per paired device. Plaintext over 2 KiB throws `PayloadTooLargeError`.
- If a device was added since the key set was fetched, the SDK refreshes recipients and retries once.
- `idempotencyKey` makes retries safe for 24 hours.
- Options: `baseUrl`, `fetch`, `maxRetries`. `Relay.fromEnv()` reads `RELAY_API_KEY` and `RELAY_API_URL`.
- **Custom API URL:** pass `baseUrl` to talk to a local, staging or self-hosted Relay instead of
  `https://relay.phuzle.com`, for example `new Relay({ apiKey, baseUrl: "http://localhost:8400" })`.

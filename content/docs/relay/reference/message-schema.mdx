---
title: Message schema
description: The v1 plaintext that is encrypted for each device.
---

| Field | Notes |
|---|---|
| `v` | Always `1` |
| `id` | Message id (ULID) |
| `ts` | Sender time, unix seconds |
| `title` | Required, up to 120 characters |
| `body` | Up to 1000 characters |
| `priority` | `min`, `low`, `default`, `high`, `urgent` |
| `tags` | Up to 5, each up to 24 characters |
| `icon` | Built-in glyph key (no remote images) |
| `url` | HTTPS link opened on tap |
| `group` | Stacking key |
| `actions` | Up to 3: `label`, `request { method, url, headers?, body? }`, `style`, `confirm`, `retry` |
| `via` | Set to `github` for server-assisted messages |

The whole serialized message must fit in **2048 bytes**. Unknown fields are ignored, so clients
stay forward-compatible.
